01 · The project

A separate path, shared affection.

ZHSan, or Zhonghua Sanguozhi (中华三国志), is another project team’s game and brand. It is not a Season-owned product, an edition of SanguoSeason, or the new Sanguo3D project.

This site introduces the SeasonRealms/ZHSan branch as a friendly, independently maintained companion. Its place here is a link from the home page, not one of the site’s four main product columns.

This is not the official Zhonghua Sanguozhi website. We do not speak for the original team or its community.

02 · Reading room

Know which branch you are using

When looking for information or reporting an issue, identify the branch you are using. A change in SeasonRealms/ZHSan does not necessarily describe the original project.

The repository’s current instructions are the reference for its technical requirements. Before reusing code, artwork, or data, check the applicable terms there; inclusion on this site grants no new rights.

03 · Workshop

Maintenance and platform status

The branch has a cross-platform direction. Its project notes list Windows and Android as tested; other targets have not been verified there. A source-code target is not the same as a ready-to-install release.

Reports should identify the branch, build, platform, and reproduction steps. Refer to the repository for changes made after this page was prepared.
